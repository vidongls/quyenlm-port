# QuyenLM Portfolio

Interactive product design portfolio built with React, TanStack Start, Tailwind CSS, and Cloudflare Workers.

## Development

```bash
pnpm install
pnpm dev
```

The local app runs at `http://localhost:3000`.

## Quality checks

```bash
pnpm typecheck
pnpm check
pnpm build
```

## Project structure

- `src/routes` — file-based application routes
- `src/components` — reusable UI and canvas components
- `src/design-tokens.css` — colors and semantic design tokens from Figma
- `src/styles.css` — global layout and component styles

## Deployment

```bash
pnpm deploy
```
